# Earlier Exploratory Scripts

This folder contains two preliminary Python scripts developed during the initial stages of the HIES 2022 analysis:

- `pre_boruta_pipeline_hies_women.py`
- `primary_exploratory.py`

These scripts document preliminary data cleaning, missing-value handling, exploratory analysis, and feature preparation. They are retained for transparency and documentation of the research development process.

**These scripts are not part of the final analytical pipeline used to produce the results reported in the manuscript.** The final analysis is implemented in `code/python/main_analysis.py` and its accompanying supporting scripts. Researchers seeking to reproduce the reported results should follow the instructions in the main repository README.
